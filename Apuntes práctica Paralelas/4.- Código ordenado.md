# Carpeta source
Contiene todos los archivos con la extensión `.c`.

## main.c
Por ahora solo mantiene la creación de una función básica con sus puntos, utilizando los métodos necesarios y dando el resultado del gradiente.

```C
#include <stdio.h>

#include "gradiente.h"
#include "casos_prueba.h"

int main() {
    int num_funciones;

    Function *funciones = crear_caso_basico(&num_funciones);
    double *punto = crear_punto_basico();
    double **gradientes = crear_gradientes(funciones, num_funciones);

    calcular_gradientes(funciones, num_funciones, punto, gradientes);

    for(int f = 0; f < num_funciones; f++) {
        printf("Gradiente funcion %d: ",f);

        for(int v = 0; v < funciones[f].num_variables; v++){
            printf("%.2f ", gradientes[f][v]);
        }

        printf("\n");
    }

    liberar_gradientes(gradientes, num_funciones);
    liberar_funciones(funciones, num_funciones);
    free(punto);

    return 0;
}

```

## casos_prueba.c
Contiene la lógica de la creación de un caso de funciones básicas de ejemplo:

```text
En un array de funciones: 
- Función 0 --> f1(x,y,z) = 3xy + 4yz + 2x + 5
- Función 1 --> f2(x,y,z) = x² + yz + 3z
```

Crear un punto básico:

```text
Puntos (x, y, z) = 1, 2, 3 -> respectivamente
```

Crear las funciones de prueba en base al número de funciones, variables y monomios elegidos por el usuario, donde cada coeficiente está entre 1 y 5. 


También esta la versión donde el usuario es quién pone cada coeficiente y cada variable en según su posición.

Crear los puntos de prueba en base al número de variables elegidos por el usuario, donde se suele alternar entre 1, 2 y 3 cíclicamente. 

```text
EJEMPLO:
x = 1
y = 2
z = 3
t = 1
l = 2
n = 3
...
```

También, con su respectiva versión donde el usuario es quién pone cada valor de cada punto.

Crear los gradientes y liberar las memorias de cada función y gradiente.

# Headers
Las cabeceras donde contiene las estructuras y los métodos declarados. Ahí se encuentra una explicación breve de qué hace cada una.

## gradiente.h
Contiene las estructuras que definen una función y un monomio. La explicación se encuentra en `Código sin paralelizar`.

También contiene los métodos relacionados al cálculo del gradiente:
* potencia -> calcula la base^exponente
* derivar_monomio -> calcula la derivada del monomio respecto a una variable
* calcular_gradiente -> calcula el gradiente
* calcular_gradientes -> calcula los gradientes de un array de funciones

## casos_prueba.h
Contiene los métodos relacionados con la creación de funciones en según el caso elegido por el usuario:
* crear_caso_basico -> crea el caso conceptual del ejemplo que hemos utilizado en `Código sin paralelizar`.
* crear_punto_basico -> crea el punto básico (x, y, z) -> (1, 2, 3)
* crear_funciones_prueba() -> crea las funciones de prueba en base a la cantidad de funciones, variables y monomios dichas por el usuario
* crear_funciones_usuario() -> asigna el valor de cada función dicha por el usuario
* crear_punto -> crea los puntos bajo el algoritmo cíclico 1, 2, 3, 1, 2, 3...
* crear_punto_usuario -> asigna el valor que el usuario escoge para cada punto
* crear_gradientes -> reserva la memoria para el resultado de los gradientes
* liberar_funciones -> libera la memoria del array de funciones
* liberar_gradientes -> libera la memoria del array de gradientes
